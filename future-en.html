A SIMPLE CONNECTION

From a response to a real smile.

“Blendshapes” are expression controls: how much to smile, blink or open the mouth. They describe a face. A robot-specific translator turns those values into movement.

WHY THIS MATTERS

Keep the character.
Change how it appears.

One software foundation

The opportunity is to carry Galatea’s personality, memory and expression logic from a screen to a physical face.

Work with robot makers

Galatea provides the conversational character. A hardware partner provides the robot and the controls needed to move it.

A practical next step

Match the expression controls, calibrate the motors, then test movement limits, timing and expression quality on real hardware.

A little more technical detail

Each robot needs a mapping between expression values and its own motors. Those values are not universal motor commands. Calibration must account for the face’s mechanics, available movements and operating limits. A completed Galatea-to-robot integration has not been demonstrated here.
